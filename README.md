# MultiAnimalEntry_aDunkle

This program allows you to compile the amounts of different animals, their daily food requirements, and view a summary of this data. It will provide a list of program options on start-up.

Program options are:
  1. Add animal
  2. View summary
  3. Exit

Note: If you fail to choose a valid option, the program will ask for a new input.

# Usage Instructions:
To run and use the program, simply compile and run the code in VS Code.
